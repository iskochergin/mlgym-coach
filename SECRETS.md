# Секреты и .env

Все секреты живут в локальном файле `.env` в корне репозитория. **Он никогда не коммитится** — `.env` уже в `.gitignore`.

## Как подключить свой OpenAI-ключ

1. Открой `.env` в корне репо.
2. Замени плейсхолдер на свой ключ:
   ```
   OPENAI_API_KEY=sk-REPLACE-ME      ← вставь сюда свой настоящий ключ
   ```
3. Сохрани. Готово — `agent/llm_client.py` сам подхватит ключ через `python-dotenv`.

## Переменные `.env`

| Переменная        | Назначение                                | Дефолт                        |
|-------------------|-------------------------------------------|-------------------------------|
| `OPENAI_API_KEY`  | Ключ OpenAI                               | `sk-REPLACE-ME` (плейсхолдер) |
| `OPENAI_BASE_URL` | Базовый URL API (для прокси/совместимых)  | `https://api.openai.com/v1`   |
| `OPENAI_MODEL`    | Модель                                    | `gpt-5-mini`                  |
| `MLGYM_LLM`       | `mock` (заглушка) или `openai` (реальный) | `openai`                      |

## Поведение клиента

- `MLGYM_LLM=mock`, либо ключ отсутствует, либо ключ всё ещё `sk-REPLACE-ME`
  → используется **MockLLM** (детерминированные ответы, без сети и трат).
- Иначе → реальный клиент через `openai` SDK.

## Правила

- **Никогда** не вставляй настоящий ключ в коммиты, код, README или историю.
- **Никогда** не убирай `.env` из `.gitignore`.
- Если ключ случайно попал в гит — считай его скомпрометированным, отзови в кабинете OpenAI и выпусти новый.
